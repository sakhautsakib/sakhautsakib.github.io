Sakhaut Sakib - Portfolio Website
=================================

ফোল্ডারের গঠন
  index.html        মূল পেজ (এটি ব্রাউজারে ডাবল-ক্লিক করে খুলুন)
  css/style.css     সব ডিজাইন/স্টাইল
  js/app.js         সাইটের কোড + অ্যাডমিন প্যানেল
  js/content.js     সাইটের সব লেখা, সেটিংস, লিংক, অ্যাডমিন পাসওয়ার্ড (হ্যাশ করা)
  assets/           লোগো, ছবি, ফেভিকন

অ্যাডমিন প্যানেল
  প্রতিটি পেজের একদম নিচে ডানদিকে ছোট "Admin" লিংক আছে।
  সেখানে ক্লিক করে আপনার আগের পাসওয়ার্ড দিয়ে লগইন করুন।

পরিবর্তন প্রকাশ (publish) করার নিয়ম
  1) অ্যাডমিনে পরিবর্তন করে "Save" চাপুন (এটি শুধু এই ব্রাউজারে সেভ হয়)।
  2) Admin > export ট্যাবে "Download content.js" চাপুন।
  3) ডাউনলোড হওয়া content.js দিয়ে js/ ফোল্ডারের পুরনো content.js বদলে দিন।
  4) পুরো ফোল্ডার আবার হোস্টিংয়ে আপলোড করুন।

প্রকাশের আগে
  index.html এ YOUR-DOMAIN লেখাটি আপনার আসল ডোমেইন দিয়ে বদলান।
  ৮ MB এর বড় ভিডিও/অডিও আপলোড হবে না; YouTube/Vimeo লিংক ব্যবহার করুন।
